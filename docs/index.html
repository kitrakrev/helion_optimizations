Helion Optimizations

Working repo for the GPU MODE Helion Kernel Challenge: Helion kernels for production LLM patterns on B200 GPUs.

View on GitHub← kitrakrev.github.io

What it does

Submissions, autotuning scripts and reference code for the Helion Kernel Challenge, which asks for Helion kernels submitted to the GPU MODE KernelBot leaderboard on B200 GPUs. The README is minimal; this summary is drawn from the repo's challenge notes and code.

ProblemDescription
causal_conv1dCausal depthwise 1D convolution (Mamba/Mamba-2)
fp8_quantPer-token-group FP8 E4M3 quantization
gated_deltanet_chunk_fwd_hInter-chunk state recurrence for Gated DeltaNet
gated_deltanet_chunk_fwd_oOutput computation for Gated DeltaNet
gated_deltanet_recompute_w_uWY-transform forward kernel for Gated DeltaNet

How it works

Reference + task spec → Local autotune on B200 → Hardcode per-shape configs → Submit to KernelBot
  • Autotuning runs locally (autotune_*.py) because submissions can't rely on the autotuner under leaderboard timeouts; best configs are hardcoded per shape.
  • Variants compare the Triton and TileIR backends and PTXAS Advanced Controls Files (*_acf.py, .acf files).
  • submit_all_leaderboard.sh submits all five problems.
